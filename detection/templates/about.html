Brain Tumour Detection System

Artificial Intelligence Powered Brain MRI Analysis using Deep Learning (CNN)

Project Overview

Brain Tumour Detection System is an AI-powered web application developed using Django and Convolutional Neural Networks (CNN). The system analyzes MRI brain scan images and predicts whether the patient has a brain tumour or not. The objective is to assist in early diagnosis by providing quick and accurate predictions.
